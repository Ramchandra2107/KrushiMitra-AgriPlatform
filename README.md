# 🌾 Agriculture Assistant

An AI-powered **Agriculture Assistant** built using the **MERN Stack** to help farmers make better decisions by providing crop disease detection, weather information, government scheme updates, and intelligent assistance through voice and chat.

## 📌 About the Project

Agriculture plays an important role in the economy, but farmers often face challenges such as identifying crop diseases, accessing government schemes, checking weather conditions, and getting reliable agricultural information.

This project provides a **single digital platform for farmers** where they can access useful agricultural services through an easy-to-use interface.

## 🚀 Features

### 🌱 Crop Disease Detection

* Detects possible diseases in crops using images.
* Helps farmers identify crop health problems at an early stage.
* Provides information and guidance based on the detected disease.

### 🎙️ Voice Assistant

* Allows users to interact with the application using voice.
* Helps farmers access information without requiring extensive typing.
* Provides a more accessible and user-friendly experience.

### 🤖 AI Chatbot

* Interactive chatbot for agriculture-related queries.
* Provides quick answers to common farming questions.
* Helps users get information about crops, diseases, farming practices, and other agricultural topics.

### 🏛️ Government Schemes

* Provides information about government schemes available for farmers.
* Helps users discover relevant agricultural subsidies and support programs.
* Makes important government information easier to access.

### 🌦️ Weather Forecast

* Provides weather information and forecasts.
* Helps farmers plan agricultural activities based on weather conditions.
* Useful for decisions related to irrigation, spraying, harvesting, and cultivation.

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone <your-repository-url>
```

### 2. Navigate to the project directory

```bash
cd Agriculture-Assistant
```

### 3. Install dependencies

```bash
npm install
```

If frontend and backend have separate dependencies:

```bash

npm install

cd ../server
npm install
```



## ▶️ Run the Project

Start the development server using:

```bash
npm run dev
```

The application will run in development mode.
